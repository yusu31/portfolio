## ⚠️ 本セッションで見つけた自分の誤り（Issue #377 で訂正済み）

**SESSION9 の HANDOFF が書いていた未解決事項「球体は回転で落下感を出せない」は誤りだった。**
実コードを読めば分かることを、読まずに設計書へ持ち込んだ。

| 誤っていた前提 | 実際 |
|---|---|
| 球は無地 | **320面 + `flatShading`**（`CrystalBall.tsx:50-52`）。コメントにも「サッカーボール風の細かい多角形面」 |
| 球には向きが無い | 面の陰影・**屈折像**（`transmission 0.7`）・**ハイライト**（`clearcoat 1.0`）の3系統で向きが読める |
| 回転させる手段がない | **実装・マージ済み**（PR #262）。`ball/roll.ts` が全旅程で約27回転させている |

**真因は `roll.ts:36` の `step.y = 0`**（転がりを生むのは水平移動のみ）。
垂直優勢の落下軌道では回転がほぼ止まる。ドリブルのバウンドで回らないのは正しい物理だが、
同じ規則を落下に適用すると「落ちているのに止まって見える」。

→ **Lempens の手法（アバターの宙返り）はそのまま使える。** 落下区間だけ回転則を差し替える。
