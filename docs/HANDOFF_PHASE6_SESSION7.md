## 決定: C を軸に、B の強みを部分移植する

| | カメラ | 主役 | 判定 |
|---|---|---|---|
| A | 章ごとに飛ぶ(不連続) | 人物 | 採らない |
| B | 一本道を連続移動 | 人物(背面追従) | **部分移植のみ** |
| **C** | **動かない。ワールドが流れる** | **球体** | **採用** |

理由:
1. **球体が主役として成立するのは C だけ**。「基本は球体の冒険」という前提に構造的に合う
2. 章 = 独立したカードという持ち方が「個人プロジェクトのハブ」という情報構造と一致する。
   奥に次の島が見えているのは「次のプロジェクトがある」ことの視覚化になる
3. **拡張コストが一番低い**。プロジェクトが増えたらカードを1枚足すだけ。
   B は世界がつながっているので道を延長して街を作り直す必要がある

B から移植するもの: **建物の壁の情報(窓・看板)** と **上部を横切る構造で画面を締める発想**。
A から移植するもの: 無し。
