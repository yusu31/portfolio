## 未解決事項

- **球体は回転で落下感を出せない。** Lempens の落下（スカイダイブ）の本体は「カメラを回さずアバター本人を宙返りさせる + シェイク + パーティクル」（`github.com/sebastien-lempens/webgl-skydiving` で確認済み）。**主役を球体のみに決めたので、球には向きが無くこの手法が成立しない。** 代替（軌跡パーティクル / 世界が上へ流れる速度感 / 雲ヴェール）を設計書で詰める
- **輪郭線を採るかは保留。** `?ol=0` の撮り比べでは差が限定的だった。**輪郭線が要る理由は「壁に情報が無いから溶ける」とも言えるので、窓を入れると要否が変わる。** 窓を入れてから測って決める
- **Q6c（全部を街に）と Q8a（ボールリレー全部残す）の両立。** コート3倍化・タッチライン際カメラという ② の配置設計の根拠が消えるので、リレーの動きの語彙は残すが座標は全部引き直しになる
- **期限を切らない**ので、常に動く状態を保ちながら少しずつマージする運用にする
