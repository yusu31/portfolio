- ~~**球体は回転で落下感を出せない。**~~ → **この前提そのものが誤りだった（Issue #377 で訂正）。**
  球は320面の `flatShading` 多面体で、回転は `ball/roll.ts` に実装済み（全旅程で約27回転、PR #262）。
  真因は `roll.ts:36` の `step.y = 0`（転がりを生むのは水平移動のみ）で、**垂直優勢の落下では回転が止まる**こと。
  → 設計書 §7。**落下区間だけ回転則を差し替える**（軸をカメラ右手方向に取って前方宙返りにする）。
  Lempens の手法はそのまま使える。**落下は街区の上で起こす**（開けた敷地は参照物が無く速度が読めない）
