## QAノブ

```
MSYS_NO_PATHCONV=1 node scripts/qa-proto-shots.mjs /city <outDir> '<plansJson>'
```

Git Bash からは `MSYS_NO_PATHCONV=1` が必須。ヘッデッド必須。ビューポートは 1280×800（= 16:10、設計の基準と一致）。

| ルート | ノブ |
|---|---|
| `/city` | `?leg=N` `?at=` `?ph=street\|open\|venue\|exit` `?ol=0` `?warp=0` `?land=0` |
| `/proto/b` | `?leg=N` `?at=` `?ol=0` |
| `/proto/c` | `?card=N` `?at=` `?pal=N` `?chain=0` `?sky=0` `?weave=0` `?hop=0` |
| `/scroll-poc` | `?freezeWind=1` `?hideVeil=1` `?toon=1` |

`?leg` を付けるとカメラが最初のフレームから静止し、**2回目のポーリングで収束する**。
効いているノブはオーバーレイに表示されるので、撮影条件がスクリーンショットに写る。
