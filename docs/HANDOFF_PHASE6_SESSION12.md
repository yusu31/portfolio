### PR 3 で気をつけること

- **装置1（建物の除外）は PR 2 で完了している。** PR 3 は残りの3つ:
  縁石の消滅（§1.2 装置2）/ 金網フェンス（装置3）/ 上部構造 → 照明塔・防球ネット（装置4）
- **4つは同時に発火させる**（設計書 §1.2）。1つだけを 10 ユニットかけて変えると鈍い。
  いまの `/city` は装置1だけなので「壁が無くなるだけ」で「入った」感じは出ていない
- **縁石を `t` 依存にするには `buildStrip` の持ち上げ量を関数化する必要がある**
  （現在は定数。`CURB_HEIGHT` 0.16 → 0 を導入フェーズの10ユニットで smootherstep）
- ⚠️ **新しい帯（フェンスの基礎・縁石のランプ）を足すときは `shouldFlipWinding()` に乗せる。**
  負の横位置へ伸びる帯は巻き順が裏向きになる（B のバグ。設計書 §5.3 の警告を読む）
- **§6 Step 3（開口の長さの実測）はここで閉じる。** 歩道橋が敷地から抜けて初めて
  「画面中央の帯に街のピクセルが無い」を測れる
- `maxOverheadGap` のテストは**街区に限る形へ書き換える**（敷地から上部構造が抜けるので、
  道全体で測ると必ず落ちる）

### 画素を実測する手順（SESSION12 で確立）

**「暗い」「浮いている」「硬い線」は画素を測るまで診断しない。**
スクリーンショットを base64 でページへ戻し、2D canvas の `getImageData` で読む
（`pngjs` 等の依存を足さずに済む）。ΔE は sRGB → Lab（CIE76）。
手順とスクリプトは Obsidian の `2026-08-08_SESSION12_city-street-pr2.md` に記録済み。

**仮説が複数あるときは、1つだけを消せる実験を選ぶ。**
「左の地面が暗い」の候補は巻き順・建物の影・シャドウ範囲外の3つだったが、
`side` を `FrontSide` に変えて「消えるか」を見たら1回で確定した。
